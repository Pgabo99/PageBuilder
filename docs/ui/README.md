# UI képernyőképek

Előtte-utána képernyőképek a vizuális modernizálás issue-ihoz (`u1-before/`, `u1-after/`, …). Elnevezés: `{dashboard|website|editor|editor-open}-{light|dark}[-mobile]`; a mobil képek 390 px széles nézetet mutatnak. A képek kizárólag demó adatból készülnek (elkülönített E2E Compose-projekt, generált demó fiók), személyes adatot nem tartalmaznak.

Az U2 „előtte” állapota megegyezik az `u1-after/` képeivel (azonos nézetek).
